SkillLink skill仓库一键分发 v0.1.0
====================================

一、使用方法
1. 解压本 zip 到任意目录
2. 双击 skill-link.exe 即可运行（无需安装、无需管理员权限、无需 WebView2 等运行时）

二、功能说明
1. 配置页
   - 「skill 仓库路径」：设置中央 skills 仓库目录（单一事实源），
     可手动输入或点击文件夹图标选择目录，最后点「保存路径」
   - 「AI 工具目录」：各 AI 编程工具的 skills 目录列表，
     支持添加 / 编辑 / 启用停用 / 删除，改完点「保存配置」
   - 配置保存在 %USERPROFILE%\.skill-client\config.json
2. Skills 页
   - 自动扫描仓库目录下每个含 SKILL.md 的子目录，识别为一个 skill
   - 勾选部署目标后点「部署此技能」创建 junction 链接
   - 「移除链接」只删除链接本身，绝不穿透删除真实目录
   - 冲突（目标处已有真实目录）时默认备份为 xxx.bak 后覆盖
3. 识别规则
   - 仓库目录下每个直接子目录包含 SKILL.md 即为一个 skill

三、注意事项
- 仅支持 Windows 10/11 x64
- junction（mklink /J）无需管理员权限，跨盘符可用
- 解压路径可含中文与空格
